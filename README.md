# 🌍 Text Translator

This is a simple Python script that translates user input into a selected target language using the `deep-translator` library.

## ✨ Features

- Choose a target language once at the beginning.
- Translate as many sentences as you like in a loop.
- Type `exit` anytime to quit the program.
- Auto-detects source language.
- Supports 100+ languages.

## 🛠️ Requirements

- Python 3.6 or higher
- `deep-translator` library

## 📦 Installation

1. Clone this repository or copy the script.

2. Install dependencies:

```bash
pip install deep-translator
```

## 🚀 Usage
Run the script using Python:

🌍 Text Translator
Enter target language (like 'fr', 'ta', 'en'): ta

Translating everything to 'ta'. Type 'exit' to quit.

Enter text to translate: Hello, how are you?
🔤 Translated: ஹலோ, நீங்கள் எப்படி இருக்கிறீர்கள்?

Enter text to translate: What are you doing?
🔤 Translated: நீங்கள் என்ன செய்கிறீர்கள்?

Enter text to translate: exit
Goodbye! 👋
